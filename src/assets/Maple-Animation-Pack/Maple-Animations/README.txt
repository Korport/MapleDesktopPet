Maple the Autumn Fox — animation collection

Eight transparent, endlessly looping animations in WebP and APNG.
Canvas: 384 x 384 pixels. Nine hand-sequenced generated keyframes per loop.
Open preview.html to compare all animations in a browser.
APNG files use the .apng extension and contain animated PNG data.
Email and Teams alerts are visual animation assets; connecting them to real notifications requires an application.

Motions: Idle, Wave, Head tilt, Ear perk, Thinking, Happy, Email alert, Teams alert.
